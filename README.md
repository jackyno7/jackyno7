# IT Admin Tools by MM

PowerShell-Prüfskripte und IT-Vorlagen für Windows-Administratoren, auf Deutsch und Englisch (PowerShell-Skripte: `-Language de|en`). Die Prüfskripte arbeiten nur lesend und schreiben einen HTML-Bericht mit Befunden und Empfehlungen; sie senden keine Daten an Dritte oder ins Internet, die Berichte bleiben lokal.
